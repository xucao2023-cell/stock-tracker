2. 行业方法及输入来源

苹果仍是中弱周期的消费硬件与生态服务公司。本次市场合理定价主锚继续使用正常化盈利×历史前瞻PE，DCF回答在要求资本回报下的现金流价值。严格产品/服务SOTP缺独立共享费用、资本投入和FCF，不构造伪精确拆分；合并现金流只计一次。

正常化采用FY2025、FY2026两年实际利润率作交叉，而不机械均值外推：FY2025 EBIT率约32.0%；FY2026剔退税的税前贡献代理后：

（1,580.63亿美元−1,094.17亿美元×2%−1,144.77亿美元×1%）÷4,788.34亿美元 = 32.3%。

因此首年32%的EBIT率仍可作为温和成本压力下的假设；18%税率高于FY2026约17.0%的实际税率，避免外推Q4约15%的低税率。新品和服务增长没有被直接转换成34%以上的全公司营业利润率。弱周期公司不是用强周期峰年EPS作基准，长期盈利依然是预测。

3. 盈利估值：直接算到每股

正常化净利代理 = 5,281.10亿美元×32%×（1−18%）= 1,385.76亿美元。

正常化EPS = 1,385.76亿美元÷144.5亿股 = 9.59 美元/股。

倍数仍取28–30倍：本次重新下载的FY2021Q4–FY2026Q3共20个季度末前瞻PE样本，中位28.975倍，P40约27.87倍、P60约29.82倍；新Q4观测尚未更新。它不是每日时间序列分位，供应商调整口径也不完全透明，因此保留置信限制，未因本季超预期而提高倍数。

9.59 美元/股×28倍=268.52 美元/股；×29倍=278.11 美元/股；×30倍=287.70 美元/股。

这套主锚与上次相同。新财报没有提供足够依据改动FY2027的经营利润或倍数，不能因GAAP全年EPS从旧预期升至8.98美元/股，就把一次性退税作为永久利润抬高分子。

4. DCF：逐年现金流及折现

经营路径沿用：FY2027收入5,281.10亿美元，其后增速8%、7%、6%、5.5%、5%、4.5%、4%、3.5%、3%；EBIT率从32%到FY2032升至33%后稳定；税率18%。这是自建十年预测，不是公司十年指引。

D&A为收入2.7%，资本开支为收入3.2%，增量营运资金为增量收入2%。FY2026实际现金capex率仅约1.89%、D&A率约2.80%；预测capex率更高是沿用的制造/AI投入余量，不是公司已披露支出目标。新一期other investing 23.89亿美元及无形资产等新增投入未取得完整附注，不能假定现金PP&E就是全部经济再投资。

FCFF = EBIT×（1−税率）+D&A−资本开支−增量营运资金。

首年代入：

FCFF2027 = 5,281.10亿美元×32%×82% + 5,281.10亿美元×2.7% − 5,281.10亿美元×3.2% −（5,281.10亿美元−4,788.34亿美元）×2%

=1,385.76亿美元+142.59亿美元−169.00亿美元−9.86亿美元=1,349.50 亿美元。

GAAP EBIT已含股权激励成本，不加回SBC，也不再次扣除；预测总现金流不再加“回购增速”。

折现率依据：美元rf沿用检查单缓存 4.953%（10月22日），最新财政部11月2日10Y为4.91%，相差4.3bp，未触发刷新；本次重算3年周收益156期，市场SPY beta 1.041、行业XLK beta 0.538。CAPM用市场beta，行业beta只作对照。

ERP维持4.5%自建假设；Damodaran网页11月1日隐含ERP为4.41%，其页面使用的5.29%国债参数与财政部最新利率不同，不能机械称作同一时点精确估计。本次维持4.5%并以折现率敏感性处理；不加规模/流动性溢价。

Ke = 4.953% + 1.041×4.5% ≈ 9.6%。以股权市值及有息债务权重、税前债务成本5.5%、税率18%，WACC约 9.56%，按半个百分点精度取 9.5%，上次为10%。

5. 终值和股权调整

永续增长率g=3%、增量ROIC=60%沿用旧假设。60%是轻资产生态增量回报的判断，非公司披露ROE，仍为低置信项。再投资率=g/ROIC=5%，不能一边永续增长、一边假设无需再投资。

终值年NOPAT = FY2036 NOPAT×1.03 = 2,314.04 亿美元；再投资=115.70 亿美元；终值FCFF=2,198.34 亿美元。

TV = 2,198.34 亿美元÷（9.5%−3%）= 33,820.66 亿美元。

TV现值 = 33,820.66 亿美元÷1.095^9.896 = 13,776.58 亿美元；终值占企业价值 55.5%。

期末净现金逐项桥接（PDF p2）：

现金363.05亿美元 + 短期证券204.17亿美元 + 长期证券802.13亿美元 − 商业票据19.97亿美元 − 一年内借款99.06亿美元 − 长期借款682.08亿美元 = 568.24亿美元。

净现金较Q3的621.73亿美元减少53.49亿美元。全部证券按最近披露值视为可归属股东资产，未另扣经营现金储备；经营租赁成本已在利润中，不再全额扣一次租赁承诺。新10-K未出，投资分类、限制与其他索取权仍需附注补证。

权益价值 = 显性期现值11,062.03 亿美元+终值现值13,776.58 亿美元+净现金568.24亿美元 = 25,406.85 亿美元。

每股DCF=25,406.85 亿美元÷146.30318亿股=173.66 美元/股。

146.30318亿股是最新Q4加权平均摊薄股数，作为期末完全摊薄代理；它不是PDF期末已发行145.32259亿股。PE用的144.5亿股是下一财年平均股本预测，两者不同已明确；不把全部未来未归属RSU与已作为成本处理的SBC再机械重复相加。
